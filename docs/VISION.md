# RadishDeck Vision v3

## Визуальный конструктор интерфейсов

RadishDeck --- это визуальный конструктор панелей управления
инфраструктурой.

Главная идея:

> Пользователь создаёт интерфейс управления так же, как создают сайты в
> визуальных конструкторах.

RadishDeck предназначен для системных администраторов.

------------------------------------------------------------------------

# Desktop Designer

RadishDeck Desktop --- главный инструмент создания.

В Desktop пользователь:

-   создаёт страницы;
-   добавляет элементы;
-   перемещает элементы мышью;
-   меняет размеры;
-   меняет расположение;
-   создаёт дизайн;
-   добавляет фон;
-   добавляет логотипы;
-   загружает изображения;
-   назначает действия.

Desktop работает как WYSIWYG-конструктор.

Принцип:

> Что создано в Desktop, то отображается в Web.

------------------------------------------------------------------------

# Canvas Profiles

Каждый проект имеет рабочий холст (Canvas).

Canvas определяет:

-   ширину;
-   высоту;
-   разрешение;
-   ориентацию;
-   фон;
-   оформление.

Примеры:

## Desktop Full HD

    1920 x 1080
    Landscape

## Desktop 2K

    2560 x 1440
    Landscape

## Desktop 4K

    3840 x 2160
    Landscape

## Mobile

    390 x 844
    Portrait

## Tablet

    1280 x 800
    Landscape

Также пользователь может создать Custom профиль:

    Width: 1024
    Height: 768

------------------------------------------------------------------------

# Device Profiles

Один проект может иметь несколько профилей:

-   Desktop;
-   Tablet;
-   Mobile;
-   Custom.

Renderer использует профиль для отображения интерфейса.

Источник данных остаётся один:

    Deck

------------------------------------------------------------------------

# Element System

Element --- универсальный объект интерфейса.

Типы элементов:

-   Button;
-   Text;
-   Image;
-   Logo;
-   Widget;
-   Container.

Структура:

    Element

    ├── Layout
    │   ├── Position
    │   ├── Width
    │   └── Height
    │
    ├── Content
    │   ├── Text
    │   ├── Image
    │   └── Icon
    │
    ├── Appearance
    │   ├── Background
    │   ├── Border
    │   ├── Radius
    │   └── Shadow
    │
    ├── Behavior
    │   ├── Animation
    │   └── States
    │
    └── Action

------------------------------------------------------------------------

# Button Element

Кнопка является полноценным визуальным объектом.

Настройки:

## Внешний вид

-   текст;
-   картинка;
-   логотип;
-   иконка;
-   цвет;
-   фон;
-   размер;
-   стиль.

## Действие

Пользователь выбирает:

    Программа:
    [ Выбрать файл ]

Можно указать:

-   приложение;
-   скрипт;
-   команду;
-   параметры.

## Поведение

Состояния:

-   Normal;
-   Hover;
-   Pressed;
-   Running;
-   Success;
-   Error;
-   Disabled.

------------------------------------------------------------------------

# Unified Renderer

Desktop Preview и Web Runtime используют один Renderer.

                 Deck

                  |

          RadishDeck Renderer

            /              \

    Desktop Designer    Web Runtime

Desktop редактирует.

Web показывает.
