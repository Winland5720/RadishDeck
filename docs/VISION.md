# RADISH DECK - Vision
Version: 0.2.1-alpha

RadishDeck — универсальная система создания персональных панелей управления.

RadishDeck.Desktop — Конструктор.
RadishDeck.Server — Мозг системы.
Web/Mobile — Пульты через API.

Desktop используется для создания страниц, элементов, стилей и действий.
Server хранит Deck, выполняет Actions и отдаёт API.

Главный принцип: один Layout, один Renderer.
