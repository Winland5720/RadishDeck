# RadishDeck Vision

## Идея проекта

RadishDeck --- локальная платформа управления для системных
администраторов.

Главная идея: создать визуальный конструктор рабочих панелей, похожий на
Tilda, но для задач администрирования.

Пользователь создаёт свою панель:

-   добавляет элементы;
-   меняет расположение;
-   назначает действия;
-   управляет внешним видом;
-   подключает инструменты.

## Основная концепция

    Deck
     |
     ├── Pages
     |
     └── Elements
            |
            ├── Appearance
            |
            └── Actions

Element --- базовый строительный блок интерфейса.

Элементы могут быть:

-   кнопками действий;
-   информационными блоками;
-   статусами сервисов;
-   ссылками;
-   виджетами;
-   управляющими элементами.

## Локальная админская панель

RadishDeck работает внутри локальной сети.

Примеры:

Дом: - NAS - камеры - роутер - VPN - сервер

Бизнес: - серверы - резервное копирование - камеры - интернет -
оборудование



## Подключение устройств

Цель --- минимизировать ручную настройку.

Пользователь не должен: - искать IP; - создавать DNS-записи; - выполнять
сложную настройку.

Будущая идея:

    Компьютер с RadishDeck

            |
            QR-код
            |
            ↓

    Телефон / планшет

QR используется для безопасного подключения устройства.

## Pairing устройств

Будущая система:

1.  Администратор нажимает "Подключить устройство".
2.  RadishDeck создаёт временный токен.
3.  Генерируется QR-код.
4.  Устройство сканирует QR.
5.  Сервер подтверждает подключение.
6.  Устройство получает свой токен доступа.

## Безопасность

Принципы:

-   локальная работа по умолчанию;
-   явное подключение устройств;
-   токены доступа;
-   возможность удалить устройство;
-   отсутствие обязательного облака.

## Не цель проекта

RadishDeck не должен становиться:

-   заменой Zabbix;
-   облачным сервисом;
-   заменой всех существующих систем;
-   сложным DevOps-инструментом.

Цель --- дать администратору удобную точку управления.

## Главная идея

RadishDeck --- это панель управления администратора.

Не важно, сколько систем используется внутри. Администратор открывает
один интерфейс и получает быстрый доступ к нужным инструментам.

> Tilda для сисадминов: не создавать сайты, а создавать свои панели
> управления.
