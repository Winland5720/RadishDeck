---

# 1. Описание проекта


Radish Deck — это персональный центр управления компьютером.

Главная цель проекта:

Создать рабочий инструмент для управления Windows ПК,
мониторинга системы и выполнения действий.


Radish Deck предназначен в первую очередь для:

- системных администраторов;
- опытных пользователей;
- домашних серверов;
- рабочих станций.


---

# 2. Главная идея


Radish Deck объединяет:


- управление компьютером;
- запуск приложений;
- управление звуком;
- мониторинг системы;
- Docker;
- выполнение команд;
- удалённое управление.


Основной принцип:


Сначала функциональность.

Потом дизайн.


Radish Deck должен быть:

- удобным;
- стабильным;
- расширяемым;
- понятным.


---

# 3. Что такое Radish Deck


Radish Deck состоит из двух частей:


## Radish Deck Desktop


Главное Windows приложение.


Файл запуска:


RadishDeck.exe



Desktop приложение является главным центром управления.


Внутри находятся:


- Core;
- Server;
- Interface;
- Designer;
- Settings;
- Plugins;
- Logs.


---

## Radish Deck Client


Удалённый клиент.


Варианты:

- Web;
- Mobile;
- Tablet.


Client используется только для управления.


Client получает:

- интерфейс;
- страницы;
- элементы;
- состояние системы.


Client не содержит:

- сервер;
- настройки;
- Designer;
- бизнес-логику.
