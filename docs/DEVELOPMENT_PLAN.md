# RADISH DECK

# DEVELOPMENT PLAN

Версия:

Alpha 0.1.0

------------------------------------------------------------------------

# 1. Назначение

Этот документ описывает порядок разработки Radish Deck.

Главный принцип:

Сначала рабочее ядро. Потом расширение функциональности. Потом улучшение
интерфейса.

Разработка идёт по этапам:

    Architecture

    ↓

    Core

    ↓

    Server

    ↓

    Database

    ↓

    API

    ↓

    Client

    ↓

    UI

    ↓

    Features

------------------------------------------------------------------------

# 2. Текущий этап

Версия:

Alpha 0.1.0

Цель:

Создать минимально рабочее ядро Radish Deck.

Результат этапа:

Программа запускается, создаёт базовую структуру данных, поднимает
сервер, отвечает через API, поддерживает WebSocket соединение.

------------------------------------------------------------------------

# 3. Alpha 0.1.0 Development

Alpha 0.1.4 добавляет первый проверяемый поток выполнения:
`Element → Action → Executor → Service → State`.

## Step 1 --- .NET Solution

Создать:

    src/

    RadishDeck.sln

    RadishDeck.Core

    RadishDeck.Desktop

    RadishDeck.Server

    RadishDeck.Infrastructure

Проверка:

Solution открывается в Visual Studio.

------------------------------------------------------------------------

## Step 2 --- Core

Создать основу приложения.

Добавить:

-   базовые модели;
-   конфигурацию;
-   систему логирования;
-   общие интерфейсы.

Проверка:

Core собирается без ошибок.

------------------------------------------------------------------------

## Step 3 --- Database

Добавить:

SQLite

Создать:

-   подключение;
-   инициализацию;
-   базовые таблицы.

Проверка:

После запуска создаётся база данных.

------------------------------------------------------------------------

## Step 4 --- Server

Создать встроенный сервер.

Использовать:

ASP.NET Core

Добавить:

-   HTTP API;
-   WebSocket сервер.

Проверка:

Сервер запускается отдельно.

------------------------------------------------------------------------

## Step 5 --- Desktop Application

Создать Windows приложение.

Функции:

-   Splash Screen;
-   главное окно;
-   запуск сервера;
-   отображение состояния.

Проверка:

Radish Deck запускается как приложение Windows.

------------------------------------------------------------------------

## Step 6 --- API

Создать первые методы:

    GET /status

    GET /layout

    POST /settings

Проверка:

API отвечает корректно.

------------------------------------------------------------------------

## Step 7 --- WebSocket

Добавить:

-   подключение клиентов;
-   отправку событий;
-   обработку ошибок.

Проверка:

Несколько клиентов могут подключиться одновременно.

------------------------------------------------------------------------

# 4. Что НЕ делаем в Alpha 0.1.0

Запрещено добавлять:

-   полноценный Designer;
-   Drag & Drop;
-   темы;
-   плагины;
-   мобильные приложения;
-   сложные анимации.

Причина:

Эти функции относятся к следующим этапам.

------------------------------------------------------------------------

# 5. Критерии завершения Alpha 0.1.0

Alpha считается завершённой если:

✅ приложение запускается;

✅ сервер запускается;

✅ SQLite создаётся;

✅ API работает;

✅ WebSocket работает;

✅ данные сохраняются после перезапуска;

✅ документация обновлена.

------------------------------------------------------------------------

# 6. Следующий этап

После завершения Alpha 0.1.0:

    Alpha 0.2.0

    Designer Foundation

Цель:

Создание системы элементов, layout и базового конструктора.

------------------------------------------------------------------------

# 7. Правила разработки

Каждый этап:

1.  Документация

2.  Реализация

3.  Проверка

4.  Commit

5.  Следующий этап

Нельзя переходить дальше, если текущий этап не проверен.
