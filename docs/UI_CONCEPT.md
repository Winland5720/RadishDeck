# RadishDeck UI Concept

Целевая концепция согласована с [Vision v3](VISION.md),
[Architecture v3](ARCHITECTURE.md) и [Designer Specification](DESIGNER_SPEC.md).
Описание возможностей не означает, что они уже реализованы.

## Desktop Designer

RadishDeck — визуальный конструктор панелей управления инфраструктурой
для системных администраторов. Пользователь создаёт страницы, оформление
и действия в WYSIWYG-редакторе.

Главное окно:
- сверху File / Edit / View и выбор профиля устройства;
- слева библиотека элементов;
- в центре Canvas с настоящим Preview Renderer;
- справа свойства выбранного элемента;
- служебные настройки и управление Server доступны в Desktop.

Canvas поддерживает выделение, перемещение мышью, изменение размеров,
порядка слоёв, копирование и удаление элементов.

## Canvas и профили

Canvas задаёт ширину, высоту, разрешение, ориентацию, фон и ресурсы.
Размеры вроде 1920×1080 или 390×844 являются допустимыми профилями.
Device Profiles: Desktop, Tablet, Mobile и Custom.

Layout включает Position X/Y, Width, Height и Layer.
Сетка может помогать редактированию, но не ограничивает целевую модель
наборами 1×1 или 2×2. Правила отображения определяются профилем устройства.
При одинаковом профиле Desktop Preview и Web Runtime должны совпадать.

## Элементы и свойства

Базовая библиотека Designer: Button, Text, Image, Container.
Vision также предусматривает Logo и Widget; будущие расширения Designer —
Chart, Status, Monitor, Video и Custom Plugin.

Element объединяет Layout, Content, Appearance, Behavior и Action.
Действие назначается по назначению элемента: декоративным изображениям
и тексту не требуется обязательная команда.

Appearance включает фон, цвет, изображение, рамку, скругление, тень и
прозрачность. Button поддерживает текст, иконку, изображение, логотип,
шрифт, размеры и отступы. Behavior описывает анимации и состояния
Normal, Hover, Pressed, Running, Success, Error, Disabled.

Пользователь выбирает программу через Select File и задаёт аргументы.
Подробный контракт интерфейса находится в Designer Specification.

## Edit и Preview

Edit Mode показывает инструменты редактирования, сетку и выделение.
Preview Mode показывает результат без этих инструментов.
Оба режима используют общий Renderer; отдельный Renderer не создаётся.

Web Runtime получает Deck, отображает созданное и вызывает действия через
Server. Web не является конструктором.

## UX и оформление

Интерфейс показывает состояние, доступные действия и результат выполнения.
Размеры кнопок, изображения, логотипы, темы и анимации настраиваются
пользователем. Запрета на оформление по принципам визуальных конструкторов
нет; читаемость и понятная обратная связь остаются обязательными.

Этапы Canvas, Drag & Drop, Animations, Themes и Templates определяются
Designer Specification и DEVELOPMENT_PLAN.md, а не общим запретом до Beta.
