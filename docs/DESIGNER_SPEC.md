# RadishDeck Designer Specification

## Назначение

RadishDeck Designer --- это главный инструмент создания интерфейсов
управления.

Это визуальный редактор, в котором пользователь создаёт свою панель так
же, как создают сайты в конструкторах.

Главный принцип:

> Что пользователь видит в Designer, то пользователь получает в Web
> Runtime.

# Центральная область --- Canvas

Canvas показывает будущий интерфейс.

Это не картинка, а настоящий Preview Renderer.

Пользователь может:

-   перемещать элементы мышью;
-   изменять размер;
-   выделять элементы;
-   менять порядок;
-   копировать;
-   удалять.

# Выбор программы

Пользователь не вводит путь вручную.

Пример:

    Program:

    [ Select File ]

    Arguments:

    [____________]

После выбора:

    C:\Program Files\App\App.exe

сохраняется в Deck.

# Preview Mode

Designer имеет два режима:

## Edit Mode

Доступно:

-   сетка;
-   выделение;
-   свойства;
-   изменение.

## Preview Mode

Показывает результат без инструментов редактирования.

Preview должен совпадать с Web Runtime.

------------------------------------------------------------------------

# Web Runtime

Web не имеет Designer.

Он получает Deck и отображает его через Renderer.

    Deck

     |

    Renderer

     |

    Web
