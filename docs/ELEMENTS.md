# RADISH DECK

# ELEMENT SYSTEM

Версия:

Alpha 0.1.0

------------------------------------------------------------------------

# 1. Назначение

Element System --- система компонентов интерфейса Radish Deck.

Элемент --- это объект интерфейса, который имеет:

-   внешний вид;
-   состояние;
-   свойства;
-   действие.

Основная модель:

Element

-   

State

-   

Action

-   

Properties

------------------------------------------------------------------------

# 2. Общая структура элемента

Каждый элемент должен иметь:

    Element

    |

    ├── ID

    ├── Type

    ├── Name

    ├── Properties

    ├── Layout

    ├── State

    ├── Action

    └── Style

------------------------------------------------------------------------

# 3. Типы элементов

В Alpha реализуются базовые элементы.

## Button

Основной элемент управления.

Используется для:

-   запуска действий;
-   переходов между страницами;
-   управления системой.

Пример:

    Button:

    Name:
    Restart PC


    Action:
    restart_system

Свойства:

-   название;
-   иконка;
-   действие;
-   размер;
-   состояние.

------------------------------------------------------------------------

# 4. Text

Элемент отображения текста.

Используется для:

-   заголовков;
-   информации;
-   статусов.

Пример:

    CPU Usage

    45%

Свойства:

-   текст;
-   размер;
-   выравнивание;
-   стиль.

------------------------------------------------------------------------

# 5. Image

Отображение изображения.

Используется для:

-   иконок;
-   логотипов;
-   ассетов.

Свойства:

-   путь;
-   размер;
-   масштабирование.

------------------------------------------------------------------------

# 6. Indicator

Элемент состояния.

Главная задача:

Показать состояние системы.

Примеры:

Docker:

    Docker

    Running

Server:

    Server

    Online

Состояния:

-   Online;
-   Offline;
-   Running;
-   Stopped;
-   Error.

------------------------------------------------------------------------

# 7. Widget

Динамический элемент.

Получает данные от системы.

Примеры:

## CPU Widget

Показывает:

-   загрузку CPU;
-   температуру.

## RAM Widget

Показывает:

-   использование памяти.

## Network Widget

Показывает:

-   скорость;
-   состояние соединения.

------------------------------------------------------------------------

# 8. Управляющие элементы

## Slider

Пример:

Громкость:

    Volume

    ██████░░

    60%

Свойства:

-   min;
-   max;
-   value.

------------------------------------------------------------------------

## Toggle

Переключатель.

Пример:

    Docker Auto Start

    ON

Состояния:

-   enabled;
-   disabled.

------------------------------------------------------------------------

# 9. Layout

Каждый элемент имеет позицию.

Используется Grid.

Поля:

    grid_x

    grid_y

    grid_width

    grid_height

Пример:

``` json
{
"type":"button",
"grid_x":0,
"grid_y":0,
"grid_width":2,
"grid_height":1
}
```

------------------------------------------------------------------------

# 10. State System

Каждый элемент может иметь состояние.

Button:

    Normal

    Pressed

    Disabled

Docker:

    Running

    Stopped

    Error

------------------------------------------------------------------------

# 11. Action Binding

Элемент может выполнять действие.

Связь:

    Element

    ↓

    Action

    ↓

    Executor

    ↓

    Result

    ↓

    State Update

Пример:

Кнопка:

    Start Docker

Action:

    docker.start

Result:

    Docker Running

------------------------------------------------------------------------

# 12. Properties

Каждый элемент имеет настройки.

Пример Button:

-   Name;
-   Icon;
-   Action;
-   Size;
-   Color;
-   Permission.

------------------------------------------------------------------------

# 13. Events

Элемент поддерживает события.

Alpha:

-   Click

Будущее:

-   Double Click;
-   Long Press;
-   Swipe;
-   Gesture.

------------------------------------------------------------------------

# 14. Renderer

Renderer отвечает за отображение.

Element не знает:

-   Desktop;
-   Web;
-   Mobile.

Он предоставляет:

-   данные;
-   состояние;
-   свойства.

------------------------------------------------------------------------

# 15. Правила

Запрещено:

-   создавать отдельный элемент для каждого клиента;
-   хранить дизайн внутри кода;
-   связывать элемент напрямую с Windows API.

Правильно:

    Element

    ↓

    Action

    ↓

    Executor

------------------------------------------------------------------------

# 16. Цель системы элементов

Создать универсальные компоненты.

Один элемент должен работать в:

-   Desktop;
-   Web;
-   Mobile;
-   Tablet.
