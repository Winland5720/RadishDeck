# RADISH DECK

# TESTING DOCUMENTATION

Версия:

Alpha 0.1.0

------------------------------------------------------------------------

# 1. Назначение

Этот документ описывает правила тестирования Radish Deck.

Главная цель:

Проверить, что каждая версия работает стабильно перед переходом на
следующий этап.

------------------------------------------------------------------------

# 2. Принцип тестирования

Каждый этап разработки должен заканчиваться проверкой.

Порядок:

    Разработка

    ↓

    Тестирование

    ↓

    Исправление ошибок

    ↓

    Git Commit

    ↓

    Следующая версия

------------------------------------------------------------------------

# 3. Alpha 0.1.0 Testing

Цель:

Проверить основу проекта.

------------------------------------------------------------------------

# 4. Запуск приложения

Проверить:

✓ RadishDeck.exe запускается

✓ Программа не падает при старте

✓ Создаются необходимые файлы

✓ Загружается конфигурация

------------------------------------------------------------------------

# 5. Server Testing

Проверить:

✓ Сервер запускается

✓ Сервер останавливается

✓ Сервер перезапускается

✓ IP можно изменить

✓ Port можно изменить

------------------------------------------------------------------------

# 6. Database Testing

Проверить:

✓ SQLite создаётся

✓ Настройки сохраняются

✓ После перезапуска данные не теряются

✓ Миграции работают

------------------------------------------------------------------------

# 7. API Testing

Проверить:

GET запросы:

-   status;
-   settings;
-   pages.

POST запросы:

-   изменение настроек;
-   выполнение действий.

Проверить ошибки:

-   неправильные данные;
-   недоступные ресурсы.

------------------------------------------------------------------------

# 8. WebSocket Testing

Проверить:

✓ клиент подключается

✓ клиент отключается

✓ сервер отправляет события

✓ состояние обновляется

✓ несколько клиентов работают одновременно

------------------------------------------------------------------------

# 9. Client Testing

Проверить:

✓ Web Client открывается

✓ Mobile Client подключается

✓ Tablet Client подключается

✓ Layout отображается одинаково

------------------------------------------------------------------------

# 10. Network Testing

Проверить:

✓ Работа через локальную сеть

✓ Работа через выбранный IP

✓ Работа через Wi-Fi

Запрещённые проверки:

localhost

127.0.0.1

------------------------------------------------------------------------

# 11. Action Testing

Проверить:

System:

-   Restart;
-   Shutdown;
-   Lock.

Applications:

-   запуск программы;
-   запуск скрипта.

Sound:

-   изменение громкости.

------------------------------------------------------------------------

# 12. Error Testing

Проверить:

-   сервер недоступен;
-   клиент потерял соединение;
-   действие завершилось ошибкой;
-   неправильные параметры.

------------------------------------------------------------------------

# 13. Regression Testing

После каждого изменения проверять:

✓ старые функции работают

✓ база не повреждена

✓ API не изменён без причины

✓ клиенты подключаются

------------------------------------------------------------------------

# 14. Release Checklist

Перед выпуском версии:

    [ ] Код проверен

    [ ] Ошибки исправлены

    [ ] Документация обновлена

    [ ] Git commit создан

    [ ] Версия изменена

------------------------------------------------------------------------

# 15. Цель тестирования

Radish Deck должен развиваться постепенно.

Каждая версия должна быть:

-   рабочей;
-   проверенной;
-   воспроизводимой.
