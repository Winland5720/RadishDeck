# Radish Deck

![Radish Deck](assets/branding/radishdeck_logo_horizontal.png)

## Персональный центр управления компьютером

Radish Deck --- это Windows-приложение для управления компьютером,
мониторинга системы и выполнения автоматизированных действий.

Проект создаётся как расширяемая платформа:

-   Desktop Application;
-   Web Client;
-   Mobile Client;
-   Plugin System.

Главная идея:

> Сначала рабочий инструмент. Потом дизайн.

------------------------------------------------------------------------

# Возможности проекта

## Управление системой

Планируемые функции:

-   запуск приложений;
-   выполнение команд;
-   управление питанием Windows;
-   управление звуком;
-   мониторинг состояния системы.

------------------------------------------------------------------------

## Layout System

Интерфейс строится через единую модель данных.

Поддерживается:

-   страницы;
-   элементы;
-   сетка;
-   состояния;
-   действия.

Один Layout используется для:

-   Desktop;
-   Web;
-   Mobile.

------------------------------------------------------------------------

## Designer

Конструктор интерфейсов позволяет:

-   создавать страницы;
-   добавлять элементы;
-   назначать действия;
-   изменять расположение.

------------------------------------------------------------------------

## Plugins

Расширение функциональности через плагины.

Планируемые плагины:

-   System;
-   Docker;
-   OBS;
-   другие интеграции.

# Разработка

Получение исходного кода:

``` bash
git clone https://github.com/Winland5720/RadishDeck.git
```

Сборка проекта:

``` bash
dotnet build
```

Release сборка:

``` bash
dotnet publish -c Release
```
